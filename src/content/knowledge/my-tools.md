## Architecture and design

- **PlantUML** – architecture diagrams as text. They live in Git, can be versioned and reviewed like code, and agents can read and write them.
- **draw.io** – general-purpose diagrams when a visual canvas is faster.
- **Penpot** – open-source design and prototyping tool for UX work.

## Backend quality

- **ArchUnit** – architecture rules as unit tests for Java backends, see [ArchUnit](/knowledge/archunit).

## Agentic coding

- Context and guidelines as Markdown in the repository, see [Prompt Collection and AGENTS.md](/knowledge/prompt-collection-and-agents-md).
- **MCP tools** such as Jam, which hands real bug context to an agent.

## Everyday

- **nvm** – switch Node.js versions per project.
