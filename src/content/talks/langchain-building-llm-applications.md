A hands-on introduction to LangChain for developers who want to build applications on top of large language models. Related notes: [LangChain](/knowledge/langchain).

**What the talk covers**

- The LangChain ecosystem: LangChain, LangGraph, LangSmith and the LangChain Hub.
- Core components: chains, the Expression Language (LCEL), chat models, prompt templates, document loaders, text splitters, retrievers and output parsers.
- Running models locally with Ollama, or using the OpenAI API – including how to handle API keys safely.
- Retrieval-augmented generation: adding the content of a large PDF to a prompt through a retriever.
- Structured output: turning a customer review into structured data with a JSON output parser.

**Hands-on exercises**, building on each other: from "Hello World" through chat prompts and LCEL to a multi-call chain, RAG over a PDF and structured output.
