An introduction to n8n, the node-based low-code platform for automation – from the first workflow to AI agents.

**What the talk covers**

- What n8n is, and when to self-host it or use the cloud version.
- Typical use cases: AI agents over internal documents (RAG), classifying emails, connecting systems and mapping data, quick prototypes, human-in-the-loop processes.
- Core concepts: workflows, nodes, triggers and sticky notes.
- How data flows as items between nodes, and how expressions access it.
- The most useful basic nodes: Edit Fields, Code, HTTP Request, IF, Merge, Split Out, Aggregate and Limit.
- Security: protect webhooks, use user management, keep secrets in credentials.
- Treating workflows as code – export them and keep them in version control.
- Testing: isolated nodes, exploratory and integration tests.
- AI building blocks: agents, LLM chains, vector stores, retrievers, memory, tools and guardrails.
